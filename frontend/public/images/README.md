# Imagens

As imagens de produto são renderizadas como ilustrações SVG por categoria
(`src/components/products/ProductImage.tsx`), sem arquivos de terceiros.

Para usar fotos reais, adicione `<id-do-produto>.webp` (ex.: `P001.webp`) nesta pasta
com licença de uso adequada; o componente pode ser adaptado para priorizá-las.
